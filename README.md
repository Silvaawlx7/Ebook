## Sobre o e-book

O e-book apresenta como a inteligência artificial pode apoiar a aprendizagem de ferramentas digitais por meio de explicações, exercícios e perguntas orientadoras. Aborda a organização de informações no Notion, o controle de versões com Git, a diferença entre Git e GitHub e a produção de materiais visuais no Canva.

O conteúdo também discute privacidade, autoria, verificação de informações e autonomia do estudante. Os exemplos apresentados são propostas didáticas, não relatos de experimentos realizados pelo grupo.
